# Cursor-MXG Releases

Public download repository for Cursor-MXG desktop releases.

This repository contains release binaries, signatures, and updater manifests only. The application source code and build workflow remain in a private repository.

Clients consume these public assets:

- `latest.json` — Tauri updater manifest
- `update.json` — legacy updater manifest
- `portable-latest.json` — signed Windows portable updater manifest

Download the newest installer from [Releases](https://github.com/xiaomayisjh/cursor-mxg-releases/releases/latest).
