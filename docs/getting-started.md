# 首次配置与日常使用

## 完整配置路径

```text
中转账户
   │ 登录或注册
   ▼
中转 Keys
   │ 创建/启用 Key，并绑定可用分组
   ▼
模型广场
   │ 选择模型 × 选择 Key
   ▼
已加入模型
   │ 排序、初始化 CA、接管 Cursor
   ▼
本机代理
   │ Cursor 重启后发送所选模型请求
   ▼
中转模型接口
```

## 1. 登录或注册

启动 Cursor-MXG 后，主界面先显示 **中转账户登录**。

- 点击 **登录**：在独立窗口中完成账号、验证码等登录流程；
- 点击 **注册**：在独立窗口中完成服务端提供的注册流程；
- 点击 **令牌登录**：仅在常规登录窗口无法使用，并且你已经安全取得自己的 `auth_token` 与 `refresh_token` 时使用。

密码只在独立登录窗口中提交给中转服务。桌面应用保存验证后的会话，不接收密码。不要向他人索取或发送登录令牌。

## 2. 准备中转 Key

打开左侧 **中转 Keys**。

1. 检查现有 Key 是否为启用状态，是否属于要使用的分组。
2. 如果没有可用 Key，点击 **创建 Key**。
3. 填写名称、分组和需要的额度或时间限制。
4. 创建后确认列表中没有显示“本机未保存密钥”。

额度和限额填写 `0` 表示不限。Key 的完整值默认隐藏，只有主动点击 **查看** 或 **复制** 时才临时读取。

停用或删除 Key 会让关联模型不可用。应用不会把请求静默切换到另一个 Key。

## 3. 从模型广场加入模型

打开 **模型广场**：

1. 在顶部选择模型分组；
2. 搜索或勾选一个或多个模型；
3. 点击 **批量加入**；
4. 选择一个或多个属于该分组的可用 Key；
5. 点击 **加入模型**。

每个“模型 × Key”组合都是独立绑定。同一模型分别绑定两个 Key 时，会在本地形成两个独立模型。重复加入同一组合不会重复创建。

如果页面提示分组不可用，请更换分组，或到 **中转 Keys** 检查 Key 的分组和状态。

## 4. 管理已加入模型

打开 **已加入模型**：

- 使用 **上移**、**下移** 调整顺序；
- 排在第一位的模型是默认模型；
- 点击 **刷新模型状态** 获取最新可用状态；
- 删除模型只会删除本地绑定，不会删除 Key，也不会删除历史调用记录。

模型名称显示远端模型名，分组、Key 编号和有效倍率用于区分同名绑定。

## 5. 初始化本地 CA

Cursor-MXG 通过本机代理把已加入模型接入 Cursor，因此需要先建立并信任本地证书颁发机构（CA）。

1. 在 **已加入模型** 页面点击 **初始化 CA**；
2. 如果界面显示安装命令，点击 **打开终端**，按系统提示授予权限并执行；
3. 返回应用，点击 **我已初始化，刷新**；
4. 按钮显示 **检查 CA** 后，再继续接管 Cursor。

只执行 Cursor-MXG 界面生成的本机安装命令。不要安装来自聊天、网页评论或其他未知来源的证书。

## 6. 接管 Cursor

1. 保存 Cursor 中尚未保存的工作；
2. 在 **已加入模型** 页面开启 **接管 Cursor**；
3. 阅读确认内容后继续；
4. 手动完全退出并重新启动 Cursor。

接管时，Cursor-MXG 会备份并替换相关代理配置。关闭接管时，只有在当前配置仍属于 Cursor-MXG 的情况下才恢复原值，避免覆盖其他程序后来写入的设置。

不要同时运行多个会修改 Cursor 代理配置的工具。如果页面显示 **已让出接管**，说明配置已被其他程序修改；请先处理冲突，再重新开启接管。

## 7. 在 Cursor 中使用模型

重启 Cursor 后：

1. 新建一个对话；
2. 打开模型选择器；
3. 选择已在 Cursor-MXG 中加入的模型；
4. 发送一个简单请求验证连接。

Cursor 的 **Auto** 选项继续使用 Cursor 官方模型，不会自动改为中转模型。只有明确选择已加入模型的请求才会走 Cursor-MXG。

Cursor-MXG 必须在后台运行，本机代理才能处理请求。关闭主窗口后应用仍驻留系统托盘；从托盘选择 **退出** 才会结束进程。

## 8. 查看状态和用量

常用页面：

- **数据概览**：总体运行和使用情况；
- **调用详细**：本机记录的每次调用及状态；
- **中转用量**：服务端用量统计；
- **我的订阅 / 我的订单 / 兑换记录**：账户相关记录；
- **可用渠道 / 渠道监控**：服务端公开的渠道状态；
- **中转账户 / 账户安全**：账户资料和安全操作；
- **系统设置**：语言、代理、开机启动、静默启动和软件更新。

页面是否显示取决于中转服务当前开放的功能。支付创建、第三方身份绑定、TOTP 注册和 Passkey 注册目前不在桌面端提供。

## 日常操作建议

- 修改 Key 分组后，刷新 **已加入模型** 并确认原绑定是否仍可用；
- 切换接管状态后，按提示手动重启 Cursor；
- 完全退出 Cursor-MXG 前先关闭接管；
- 发现新版本时优先使用 **系统设置 → 软件更新**；
- 账户或 Key 出现异常时，先刷新对应页面，不要反复创建重复绑定。
