# 隐私与安全说明

## 数据流

```text
登录/注册
用户 ──独立登录窗口──> 固定中转控制台
                       │
                       └──会话令牌──> 本机 Rust 服务 ──> 操作系统安全存储

模型请求
Cursor ──本机代理──> Cursor-MXG 本机 Rust 服务
                         │ 解析已加入模型及其 Key
                         ▼
                    固定中转模型接口
                         │
                         └──流式结果──> Cursor
```

Cursor-MXG 只连接产品内固定配置的中转服务，不提供任意模型端点、请求头或提供商协议配置。

## 凭据如何保存

- 登录密码只在独立登录窗口中提交给中转服务，Cursor-MXG 主界面不接收密码；
- 访问令牌、刷新令牌和完整 API Key 由本机 Rust 服务管理，并保存到操作系统安全存储；
- React 界面平时只读取账户摘要、Key 掩码和状态；
- 主动点击 Key 的 **查看** 或 **复制** 时，完整 Key 才会临时出现在界面或剪贴板；
- 登录窗口使用隔离的临时浏览器环境，登录完成或取消后会清理临时认证数据并销毁窗口。

请保护操作系统账户和解锁凭据。任何能够控制当前用户会话的程序，都可能尝试读取剪贴板、界面内容或系统凭据。

## 本机保存的数据

本机数据库保存运行所需的非秘密数据，例如：

- 账户摘要；
- Key 摘要和稳定的模型绑定；
- 模型顺序；
- 本机调用记录和统计信息；
- 应用设置。

完整 API Key 和会话令牌不保存到前端状态或普通 SQLite 字段中。卸载应用不一定自动删除操作系统安全存储、本机数据库或服务端账户数据。

## 会发送到外部的数据

明确选择已加入的中转模型时，完成请求所需的内容会发送到中转模型接口，包括可能的：

- 对话消息和提示词；
- Cursor 为当前请求提供的上下文；
- 工具调用及其结果；
- 所选模型、Key 绑定和请求元数据。

这些数据受中转服务及其上游模型提供商的隐私、保留和计费规则约束。请勿在不了解相关规则时提交机密、受监管或无权分享的内容。

Cursor 的 **Auto** 和官方模型保持原有官方路由；Cursor-MXG 只处理明确选择已加入模型的请求。

## 本地 CA 与接管 Cursor

Cursor-MXG 使用本机代理接入 Cursor，因此需要初始化并信任本地证书颁发机构（CA），并修改 Cursor 的相关代理配置。

- 只执行应用界面生成的 CA 安装命令；
- 不要安装他人发送的 CA 文件或命令；
- 开启接管时会备份原配置；
- 关闭接管时，仅在配置仍由 Cursor-MXG 持有的情况下恢复原值；
- 完全退出或卸载前应先关闭接管；
- 不要同时使用多个修改 Cursor 代理配置的工具。

本机 CA 的信任范围由操作系统和安装方式决定。如果设备由组织管理，请先获得管理员许可。

本仓库公开提供：

- Windows、macOS 和 Linux 安装包；
- 自动更新清单；
- 更新包签名。

客户端从本仓库下载更新，并使用应用内置公钥验证签名。`.sig` 和 JSON 清单用于自动更新，不是供用户执行的程序。

当前安装包可能没有 Windows 商业代码签名或 Apple 公证，因此系统可能显示来源警告。只有在下载地址确认为以下仓库时才继续：

```text
https://github.com/xiaomayisjh/cursor-mxg-releases
```

本仓库是二进制分发仓库，应用源码、构建工作流、签名私钥和私有 Git 历史不会公开到这里。

## 账户和 Key 安全建议

- 为中转账户使用独立且强度足够的密码；
- 只创建实际需要的 Key，并设置合理额度和限额；
- 不再使用的 Key 应立即停用或删除；
- 不要通过聊天、Issue、截图或日志分享完整 Key 与登录令牌；
- 使用 **复制** 后，避免让敏感值长期停留在剪贴板；
- 发现账户异常时，及时修改密码并执行服务端提供的会话撤销操作。

## 安全反馈

公开 Issue 适合报告不包含敏感信息的功能故障。提交前请移除：

- 密码、访问令牌和刷新令牌；
- 完整 API Key、Cookie 和请求授权头；
- 私密对话、提示词、文件内容和模型回复；
- 个人身份、账单和支付信息；
- 能够定位私人服务或设备的日志字段。

如果问题无法在不暴露秘密的情况下说明，请先提交最小化描述，不要把秘密作为附件上传。
